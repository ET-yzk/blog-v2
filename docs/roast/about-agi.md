# 关于 AGI

其实我关于 AI 的构想，第一反应是美剧《疑犯追踪》中的，而不是电影《钢铁侠》中的 Jvis，这很奇怪

我认为现在的基于 Transformer 架构或类似结构的模型，并不是我所认为的真正意义上的上的人工智能的形态，它的本质上，在我看来只有其形，没有其质，本质上是基于统计学上的概率计算出来的

我所认为的 AI 有几点：1.具备自我学习能力 2.和人一样是有约束的 3.具有主动性和创造性 4.
