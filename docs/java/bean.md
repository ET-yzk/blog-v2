# Spring Bean

> Spring Bean 是 Spring 框架中被管理的对象。它可以是符合特定规范的 Java 类实例。Spring 通过配置文件或注解等方式来定义个管理这些 Bean，实现了对象的创建、初始化、依赖注入等生命周期的管理。这使得应用程序的组件之间更加松散耦合，提高代码的可维护性和可扩展性。
